# Published visual evidence subset

The local analysis used 21 full-runtime contact sheets and 38 targeted frames. This public repository redistributes only the four frames directly required by the transformed reports:

- `targeted/t_0020.png` — London Through Time
- `targeted/t_0315.png` — one-shot project gallery
- `targeted/t_1105.png` — Manhattan
- `targeted/t_1725.png` — reasoning-level comparison

The raw source video, transcript, complete contact-sheet sweep and unused targeted frames are intentionally excluded from the public repository. See `../source-manifest.json` for the acquisition and coverage record, and the original [Peter Gostev video](https://www.youtube.com/watch?v=GQPi39sjNhU) for the source work.
